# Todo_List
**Next.js**와 **TypeScript**를 활용하여 구현한 할 일 관리 웹 애플리케이션입니다.

## 프로젝트 설명 및 사용 방법
**할 일 목록 페이지**는 진행 중인 할 일과 완료된 할 일을 관리할 수 있습니다.  
입력창에 할 일을 입력하고 **추가하기** 버튼이나 **enter**을 누르면 새로운 할 일을 생성할 수 있습니다.

**할 일 상세 페이지**는 할 일 항목을 클릭하면 이동할 수 있습니다.  
할 일 이름과 완료 상태 수정이 가능하며, 메모를 작성하고 이미지를 첨부할 수 있습니다.  
변경 사항이 있다면 **수정 완료** 버튼을, 할 일을 삭제하고 싶다면 **삭제하기** 버튼을 클릭합니다.
