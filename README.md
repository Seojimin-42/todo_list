# Todo_List

Next.js와 TypeScript를 활용하여 구현한 할 일 관리 웹 애플리케이션입니다.

할 일 목록 페이지에서는 진행 중인 할 일과 완료된 할 일을 관리할 수 있습니다.
입력창에 할 일을 입력하고 추가하기 버튼을 누르면 새로운 할 일을 생성할 수 있습니다.

할 일 상세 페이지에서는 이름과 완료 상태를 수정하고, 메모 작성 및 이미지를 첨부할 수 있습니다.
